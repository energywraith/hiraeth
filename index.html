Screen corners

Drag the 4 dots onto the glass corners. Click a dot, then use ← ↑ → ↓ (Shift = bigger) for fine nudges. Keys 1/2/3/4 = focus top/right/bottom/left edge, 0 = all. [ / ] = less/more bulge on the focused edge. Copy into the source.

Sky mask

Drag the dots onto the window/curtain/telescope edges. Click a dot, then use ← ↑ → ↓ (Shift = bigger) for fine nudges. Copy into src/scene/skyMask.ts.

Hotspots

Pick a hotspot, drag its dots onto the object's edges (Tab = next hotspot). Click a dot, then use ← ↑ → ↓ (Shift = bigger) for fine nudges. If a few corners aren't enough to hug the shape, click a dot and hit + point (or + key) to add one after it, − point (or - key) to remove the selected one. Copy into src/hotspots/config.ts.
