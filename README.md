# hiraeth

A nostalgic 90s bedroom, frozen at night: a CRT computer, a telescope
pointed at a full moon, stars that twinkle behind the glass, a comet
that drifts by every so often — and a living CRT screen booting up in
the corner. No game, no app, just a vibe.

![scene preview](public/scene.png)

## Getting started

Requires Node.js.

```bash
npm install
npm run dev
```

Then open `http://localhost:4173`.

Deployment isn't set up yet — for now, `npm run build` produces a static
bundle in `dist/`.
